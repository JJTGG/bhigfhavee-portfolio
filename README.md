# Favour | Bhigfhavee Designs — Portfolio website

A responsive single-page graphic design portfolio built with React + Vite.

## Run locally
1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL Vite prints.
4. Run `npm run build` to create the production build in `dist/`.

## Portfolio artwork included
The five artwork images extracted from the supplied redesigned portfolio PDF are already included in `public/images/` using these filenames:
- `birthday-flyer.jpg`
- `food-flyer.jpg`
- `fashion-flyer.jpg`
- `event-flyer.jpg`
- `skincare-ad.jpg`

If your exports are PNG or WebP instead, update the matching image paths in `src/main.jsx`. Use your original artwork and make sure you have the right to publish it.

## Contact links
The WhatsApp, email and Instagram links are set to the contact details supplied for the portfolio. Check that your Instagram handle is correct before publishing.

## Deploy
Push this project to a GitHub repository, then import that repository into Vercel. Vercel detects Vite automatically; use `npm run build` as the build command and `dist` as the output directory.
